# IPL-analysis
A data analysis project that explores IPL match statistics, team performance, player records, and key insights using Excel formulas, charts, and dashboards.
# IPL Analysis

This project analyzes Indian Premier League (IPL) data using Microsoft Excel.

## Features
- Team performance analysis
- Player statistics
- Match result insights
- Pivot Tables and Charts
- Interactive Dashboard

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Graphs
- Excel Formulas

## Project Objective
To identify trends, compare team performances, and generate meaningful insights from IPL data.
